利用しているデータベース

  • SSBD:database 顕微鏡画像や画像処理結果等を共有するDBで、遠里がv1を開発しました
  • NeuroGT database 誕生日タグ付け法のマウスの脳画像DBで、遠里がデータ整備を行いました
  • PhenoBank
  • Worm Developmental Dynamics Database 2 (WDDD2) 線虫のRNAi胚の顕微鏡画像DB
  • WormBase 線虫の遺伝子の情報を確認するためのDB
