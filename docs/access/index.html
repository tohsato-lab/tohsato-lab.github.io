計算生物学研究室は、立命館大学の大阪いばらきキャンパスのH棟6階のH623にあります。
遠里の個人研究室は同建物の6階のH6009です。

大阪茨木キャンパスへは、JR茨木駅から徒歩約5分、阪急南茨木駅から徒歩約10分です。
詳細は、立命館大学の大阪いばらきキャンパスのアクセス、およびキャンパスマップをご確認下さい。
